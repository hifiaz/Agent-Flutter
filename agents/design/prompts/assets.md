# Asset Generation Prompts

## App Icon Prompts

### Modern Minimal
```
prompt: "[app_name] app icon, modern minimalist design, clean lines, [primary_color] to [secondary_color] gradient background, simple geometric logo centered, no text, white logo, high quality, professional, 1024x1024"
negative_prompt: "text, watermark, blurry, low quality, complex, busy, multiple colors, gradients too noisy"
```

### Playful
```
prompt: "[app_name] app icon, playful design, rounded corners, vibrant [primary_color] background, cute mascot character, bouncy feel, fun, friendly, no text, high quality, 1024x1024"
negative_prompt: "text, watermark, blurry, low quality, dull, boring, corporate, serious"
```

### Professional
```
prompt: "[app_name] app icon, professional corporate design, [primary_color] solid background, minimalist logo, sharp edges, clean typography feel, no text, business quality, 1024x1024"
negative_prompt: "text, watermark, blurry, low quality, playful, cartoon, rounded, casual"
```

## Splash Screen Prompts

```
prompt: "[app_name] splash screen, centered logo on [primary_color] background, white logo, [secondary_color] accent elements, elegant, professional, minimal, high quality"

```

## Illustration Prompts

### Empty State
```
prompt: "[app_type] empty state illustration, friendly character with [app_related_item], soft [primary_color] background, encouraging message feel, clean, modern, vector style"
negative_prompt: "text, watermark, blurry, low quality, scary, alarming"
```

### Onboarding Step 1
```
prompt: "[app_name] onboarding illustration 1, showing [feature_1], happy user interacting with app interface, [primary_color] theme, clean modern style, friendly, professional"
negative_prompt: "text, watermark, blurry, low quality, cluttered"
```

### Onboarding Step 2
```
prompt: "[app_name] onboarding illustration 2, showing [feature_2], user with tablet, modern lifestyle, [primary_color] and [secondary_color] colors, clean, inspiring"
negative_prompt: "text, watermark, blurry, low quality, busy"
```

### Onboarding Step 3
```
prompt: "[app_name] onboarding illustration 3, showing success/completion, celebration feel, user happy with results, [primary_color] theme, clean modern style"
negative_prompt: "text, watermark, blurry, low quality, sad, worried"
```

### Error State
```
prompt: "[app_type] error state illustration, friendly broken robot or sad character, [app_related_item] disconnected, [primary_color] soft background, helpful not alarming, modern style"
negative_prompt: "text, watermark, blurry, low quality, scary, dark, threatening"
```
